# Copyable Agent Prompt

You are creating a GLSL visual film for a narrated essay in this repository.

Read:

1. the complete source essay/PIL pack;
2. `beautify-archive/framework/SIGNATURE-FILM-SYSTEM.md`;
3. `beautify-archive/framework/REVIEW-RUBRIC.md`;
4. `beautify-archive/framework/PRIOR-OUTPUT-AUDIT.md`;
5. `beautify-archive/lib/signature.glsl`;
6. the existing render harness.

Do not faithfully port the PIL drawing style. Preserve conceptual content and
invent an essay-specific material world.

Before GLSL, create `film_spec.json`:

- extract every unique visual function;
- state the one-sentence thesis;
- choose a continuity material capable of conflict and integration;
- map the essay to latent, formation, stress, revision, and integration;
- assign every shader one primary visual verb, causal topology, composition,
  camera behavior, `u/t/audio` semantics, and concise design rationale;
- ensure the final scene visibly preserves earlier history.

Validate the spec. Then implement one standalone fragment shader per source
visual function using a pack include plus the shared primitives, visionary,
cinema, and signature libraries.

Compile every shader. Render low, mature, and resolved states. Review full
contact sheets for meaning, composition diversity, exposure, repetition, and
continuity. Revise both spec and shaders when a decision changes. Record
evidence in `REVIEW.md`.

The target is not a set of attractive diagrams. It is a generative short film
whose changing matter, geometry, camera, motion, and color let an audience feel
and understand the essay while listening.
