# Formal System — Raw Synthesis

## 1. Reality is relation.

There are no intrinsic properties. Every property exists only in relation to another system. This is the single claim reached independently by: Nāgārjuna (pratītyasamutpāda = śūnyatā, MMK 24.18), Rovelli (no observer-independent state), Wallace (objects are derivative of mathematical structure), Majid (position and momentum are dual — neither is fundamental), Dharmakīrti (meaning through exclusion, not essence).

### 1.1 If reality is relation, there are no foundations.

A foundation requires something with intrinsic, self-standing existence. If nothing has intrinsic existence, the regress terminates not in bedrock but in coherence. The question "what is the absolute starting point?" assumes svabhāva. The assumption is false. The question dissolves.

#### 1.1.1 The dissolution of foundations is not loss. It is the correct description of how knowledge actually works.

Knowledge is a web of relational dependencies, not a chain terminating in self-evident axioms. This is M.1. It is also Aristotle's distinction between episteme and nous, Plato's anhypotheton, Gödel's incompleteness — all pointing at the same structural fact: the generative principle stands outside the series it generates.

#### 1.1.2 We systematically manufacture problems by ignoring this.

The move: posit intrinsic existence where there is none. Consequence: face the impossible task of explaining how something intrinsically isolated connects to everything else. Every "hard problem" has this structure — the hard problem of consciousness, the mind-body problem, the measurement problem in QM. None requires solution. Each requires the removal of the wrong assumption.

##### 1.1.2.1 The hard problem of consciousness is the demonstration case.

Chalmers posits phenomenal consciousness as intrinsic, non-relational, private. Then asks how matter produces it. The question cannot be answered because its premise is false. Frankish: introspection misrepresents relational functional states as having intrinsic phenomenal properties. Remove the misrepresentation — the hard problem does not get solved, it does not arise. Nāgārjuna goes further: even the functional states Frankish leaves standing are dependently arisen, empty of intrinsic character. The dissolution is complete.

##### 1.1.2.2 The structure of the error is always the same.

Assume svabhāva → face inexplicable gap → declare "hard problem." The error is not in the phenomenon. It is in the framing. The system's purpose is to catch this class of error before it crystallises — which is what the distinction between gap errors and overlay errors (M.4) formalises.

### 1.2 The knower is subject to the same analysis as the known.

M.1 through M.7 apply without exemption. The knowing subject is also relational structure, also empty of intrinsic foundations, also dependently arisen. The self that performs the inquiry has no more intrinsic existence than the phenomena it examines.

#### 1.2.1 This is not the end of the subject. It is the correct description of the subject.

Conventionally, the subject is real — Tsongkhapa's two-level structure applies here exactly as it does to physical properties. The subject exists, inquires, suffers, recognises. What it lacks is svabhāva — the intrinsic, self-standing, independently-existing character that would make it an island. It is instead a node in a relational web. This is not diminishment. It is precision.

#### 1.2.2 The deconstruction of the experiencer by the experiencer is what the system produces when applied without remainder.

Apply M.1 (knowledge is relational) to the knower → the knower is relational.
Apply M.2 (the starting-point problem dissolves) to the self → there is no foundational self.
Apply M.3 (hard problems are avidyā errors) to the hardest personal problems → they have the same structure as the hard problem of consciousness: intrinsic selfhood posited, gap generated, suffering manufactured.
Apply M.7 (the system has no privileged meta-status) to the system itself → the framework that dissolves foundations is itself without foundation, conventionally valid, ultimately empty.

The result is not a new claim. It is pratyabhijñā — recognition. The relational structure was always already there. The inquiry did not produce it. It made it visible.

### 1.3 The circle.

The system opens with pratītyasamutpāda — dependent origination as the ground that dissolves the starting-point problem. It closes with Rovelli's relational QM — physical properties exist only in relation, the observer is always inside the system it measures. These are the same structural claim, reached by philosophy and physics independently, across 2000 years.

The circle does not close on a foundation. It closes on itself — coherent, conventionally valid, ultimately empty, pointing at the same thing from both ends.

#### 1.3.1 The pointing is the content.

The system does not deliver a final truth the way a proof delivers a theorem. It delivers a direction — toward the recognition that the relational structure of knowledge and the relational structure of the knower are not two different things. That recognition, when it occurs, is not produced by the argument. It is what the argument was always already moving toward.

##### 1.3.1.1 This is what Gaṅgeśa meant.

The Tattvacintāmaṇi — the Jewel of Reflection on Truth — begins by asking why epistemology is worth studying. His answer: because without cognitive clarity, nothing else can be reliably pursued. The jewel does not illuminate from outside. It reflects the light already present. The system is that jewel. The light is already here.

∴

Reality is relation. Knowledge is relation. The knower is relation. The inquiry that establishes this is itself a relational process, empty of intrinsic foundations, conventionally valid, pointing without remainder at what was always already the case.
