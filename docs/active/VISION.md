# The Truth Map as a Refutation-Led Research Ledger

This is not a content platform. It's not a Bayesian oracle. It's not a YouTube channel disguised as a philosophy project.

It's an **adversarial research ledger** that tracks what explanations survive criticism, what evidence moved them, what would break them, and what to test next.

A new paper comes in → Nyāya gate checks its claims for fallacies → if it passes, the argument graph records support/attack edges → posteriors update as provenance bookkeeping → the system reorients toward what's still undefeated.

The factories don't produce content. They produce **testable explanations**. Content is just what an explanation looks like when it's shared for criticism.

## How It Works

The system has 5 layers:

1. **SOURCE** — faithful extraction of passages from papers, texts, and datasets (SO → RO)
2. **FORMAL** — Lean theorem proving for claims that can be formalized (Sanskritree)
3. **ARGUMENT** — Nyāya gate validates claims, argument graph tracks support/attack/crux relations
4. **EVIDENCE** — Bayesian runtime tracks posterior movement as auditable bookkeeping (F1-F8, D1-D5, B1-B6, 3 evidence dimensions)
5. **REALITY BRIEF** — state-of-play synthesis: what survives, what's weakened, what would change our mind

The pipeline:

1. **ACQUIRE** — new papers, texts, and datasets enter the system
2. **GATE** — every claim passes through Nyāya validation (hetvābhāsa, pramāṇa, falsifier checks)
3. **GRAPH** — approved claims enter the argument fabric as nodes with support/attack edges
4. **UPDATE** — Bayesian runtime records posterior movement with full provenance
5. **SYNTHESIS** — state-of-play report: live candidates, open cruxes, next tests
6. **PRODUCE** — EOs become essays and videos, each updating the truth map
7. **CONSOLIDATE** — nightly, stale questions pruned, acquisition gaps identified
8. **LOOP** — the updated ledger feeds the next cycle

## What Makes It Different

Every other system measures engagement. This one measures **what survived adversarial testing**. A video with 100K views that makes claims that can't survive the Nyāya gate is less valuable than a dossier with 1K views that documents a genuine convergence across traditions.

The primary metric is: did we weaken a bad explanation or strengthen a good one?

## The Ledger

The system records everything: what was claimed, what gate it passed, what evidence moved it, what survived criticism, what didn't. Numbers are summaries, not verdicts. Every posterior has a provenance path back to the source span that produced it.

It wakes up every morning knowing more than it did the day before. Not because it computed reality, but because it tested explanations against evidence and recorded what survived.
