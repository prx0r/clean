# Expanding Existing Packs

## General method

An existing domain pack should not reimplement geometry, particles or audio
analysis.

It should declare:

```text
domain assets
domain mechanisms
geometry dependencies
material defaults
motion presets
signal-routing presets
epistemic status
```

## Neurocognition

Add:

### Geometry dependencies

- network graphs;
- cortical ribbons;
- path-stroked tracts;
- prediction/error lanes;
- attention apertures.

### Particle uses

- neural propagation packets;
- prediction signals;
- error-return packets;
- oscillatory phase markers.

### Audio routes

- onset → spike emission;
- percussive energy → synchronous firing;
- harmonic energy → field integration;
- spectral flatness → noisy competition;
- tonal stability → phase coherence.

## Human anatomy

Add:

- exact clipping masks for body regions;
- stroked vascular and nerve paths;
- region-specific particle emitters;
- layered translucent organ materials;
- pulse, breath and peristaltic motion presets.

Keep biomedical visual modes distinct from symbolic modes.

## Invariant composition

The invariant pack should consume these visual capabilities without owning
their style.

Examples:

- `carrier-transfer` using deity ornaments, manuscript glyphs or neural tracts;
- `causal-memory` using particle trails and pigment residues;
- `semantic-transition` using boolean path transformation;
- `recognition-transaction` using material de-emphasis and relational geometry.

## Pack extension checklist

For every new mechanism:

- What relation does it encode?
- What topology makes that relation legible?
- What moves?
- What remains invariant?
- Which visual channels encode each concept?
- What audio/narration signals may modulate it?
- Which signals must never change its semantic identity?
- What epistemic mode applies?
- What does the mechanism look like without narration?
