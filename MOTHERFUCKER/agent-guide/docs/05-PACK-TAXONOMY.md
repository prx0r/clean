# Pack Taxonomy

## 1. Capability packs

Define domain vocabulary and semantic mechanisms.

Examples:

- human anatomy;
- neurocognition;
- yogic subtle body;
- tantric cosmology;
- manuscript scholarship.

## 2. Meta-composition packs

Define sequence-level structural laws.

Examples:

- invariant composition;
- dialectical development;
- recursive exposition;
- comparative inquiry;
- ritual progression.

## 3. Geometry packs

Define reusable constructed forms.

Examples:

- PathKit geometry;
- anatomical geometry;
- graph geometry;
- topological fields;
- manuscript ornament;
- sacred architecture.

## 4. Material packs

Define surface, light and compositing behavior.

Examples:

- mineral manuscript;
- ritual gold;
- luminous subtle body;
- technical neural;
- ash and ember.

## 5. Motion packs

Define transformation behavior.

Recommended future packs:

- breath dynamics;
- fluid transport;
- growth and branching;
- fracture and repair;
- phase and entrainment;
- ritual gesture;
- camera subjectivity;
- temporal memory.

## 6. Signal-routing packs

Map score, waveform and narration buses into motion/material parameters.

Examples:

- harmonic prāṇa;
- percussive neural propagation;
- mantra phoneme circulation;
- narration-first scientific explanation;
- sparse contemplative attention.

## 7. Presentation packs

Typography, framing, labels and editorial layout.

Examples:

- scientific plate;
- museum manuscript;
- ritual folio;
- cinematic minimal;
- annotated atlas.

## 8. Composition packs

Higher-level dramaturgy templates.

Recommended future packs:

### `comparative-bind`

For science versus metaphysics:

```text
model A
→ model B
→ structural bridge
→ explanatory gap
→ unresolved frontier
```

### `recognition-arc`

For Pratyabhijñā-style arguments:

```text
ordinary assumption
→ instability
→ invariant prepared
→ recognition
→ assimilation
```

### `ritual-progression`

```text
boundary
→ purification
→ installation
→ activation
→ offering
→ identification
→ dissolution
```

### `anatomical-journey`

```text
whole-body orientation
→ region
→ tissue
→ process
→ system interaction
→ return to organism
```

### `causal-explanation`

```text
initial state
→ disturbance
→ mechanism
→ feedback
→ failure mode
→ regulation
```
