# System Map

```text
Essay / source
    ↓
Argument IR
    ↓
Composition contract
    ├── continuity systems
    ├── transition verbs
    ├── recognition signature
    ├── attention allocation
    └── capability requirements
    ↓
Activated capability profile
    ├── domain packs
    ├── invariant/meta packs
    ├── geometry packs
    ├── particle packs
    └── audio/narration adapters
    ↓
Scene pack
    ├── mechanism
    ├── assets
    ├── style profile
    ├── material profile
    ├── motion profile
    └── signal routing
    ↓
Feature preparation
    ├── score-event bus
    ├── audio-feature bus
    └── narration-feature bus
    ↓
Deterministic frame renderer
    ↓
Contact sheets / motion strips
    ↓
Perceptual review
    ↓
Final render and audio mux
```

## The independent dimensions

| Dimension | Responsibility |
|---|---|
| Semantics | What the essay claims |
| Capability | What concepts can be shown |
| Composition | Why visual events occur in this order |
| Geometry | What forms exist |
| Material | How forms behave as surfaces and light |
| Motion | How forms transform |
| Style | Global directorial constraints |
| Audio routing | How performed sound modulates visuals |
| Narration routing | How speech presence and semantics direct attention |
| Presentation | Typography, borders and layout |
