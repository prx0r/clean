# Process notes

These five additional packs were produced in the same segmented-draft format as the first set: eight slow visual beats, sparse text, deterministic Pillow rendering, OpenCV frame assembly, and FFmpeg H.264 export.

## Visual system

Apophatic center, noetic constellation, descent ladders, beauty vectors, time wheel, return arc.

## Best use

Use as a continuous visual bed under narration, or cut by scene boundary using `scene_manifest.json`.
