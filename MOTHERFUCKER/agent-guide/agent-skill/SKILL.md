# Visionary Film Builder

## Mission

Compile an essay or research object into a deterministic visual program that
communicates relations through motion, not a slideshow of noun illustrations.

## Non-negotiable order

1. Read the complete source.
2. Build a visual-free argument IR.
3. Identify continuity systems and invariants.
4. Select composition structure.
5. Activate capability packs.
6. Generate at least three mechanism candidates per beat.
7. Select by relation preservation and motion proof.
8. Apply geometry, material, motion and style profiles.
9. Route music and narration signals independently.
10. Validate and render review frames.
11. Repair failed mechanisms only.
12. Render final video and mux audio.

## Required inputs

- source essay or argument IR;
- available capability-pack manifests;
- available style/material/motion profiles;
- audio or score-event manifests when reactive rendering is requested;
- narration timings when speech-aware rendering is requested;
- output directory.

## Mechanism selection rubric

Score every candidate on:

- relation preservation;
- topology;
- temporal order;
- invariant preservation;
- silent legibility;
- domain appropriateness;
- epistemic integrity;
- novelty relative to adjacent scenes.

Reject any candidate that is merely beautiful and interchangeable.

## Audio-routing rules

- Use score events for formal visual changes.
- Use waveform features for performed dynamics and timbre.
- Use narration timings for attention allocation and semantic triggers.
- Never map volume to every visual parameter.
- Always smooth routed features.
- Never let audio modulation destroy the mechanism's identity.

## Narration rules

When narration is dense:

- reduce new particle emission;
- simplify background motion;
- preserve the main explanatory geometry;
- avoid additional labels;
- keep continuity objects present.

When narration withdraws:

- allow the visual process to complete;
- do not automatically fade to black.

## Pack rules

Capability packs answer: what relation or domain can be shown?

Style packs answer: how should it feel?

Composition packs answer: why does this event follow the previous event?

Signal packs answer: which audio or narration feature controls which visual
parameter?

Never place all four responsibilities in one theme.

## Review frames

For every scene render:

```text
0.00
0.25
0.55
0.82
1.00
```

For every transition render a six-frame chronological strip.

## Hard failures

- missing pack activation;
- unsupported mechanism;
- unregistered theme;
- non-deterministic output;
- audio feature read during each frame;
- narration and music routed to identical controls;
- arbitrary symbol substitution;
- biomedical and symbolic models collapsed;
- transition implemented as an unexplained crossfade;
- scene legible only through its title.
