# PathKit Visionary Engine Overlay

A complete additive geometry, material, audio-reactivity and particle layer for
the existing deterministic `@napi-rs/canvas` framework.

It includes computed paths, lotus/yantra/mandala/flame generators, perceptual
color utilities, offscreen layer stacks, six style packs, librosa analysis,
timestamp-addressable audio features, deterministic particle fields, capability
manifests, tests, a capability probe and a demonstration pack.
