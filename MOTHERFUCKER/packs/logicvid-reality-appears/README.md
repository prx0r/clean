# Logicvid — Why Does Reality Appear?

Complete overlay for a sharp, clean, audio-synchronized argument film.

Apply from `MOTHERFUCKER/`:

```bash
node ../tools/apply-logicvid-framework-patch.mjs
bash ../tools/build-film.sh
```

The build generates TTS, analyzes narration, renders the visual, muxes audio,
and validates the result.
