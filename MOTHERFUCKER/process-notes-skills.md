# Process Notes — Logicvid 04: Why Does Reality Appear?

## Goal
Create a reusable skill pattern for producing "Logicvid" formal philosophy videos using the argument-diagram motif.

## Source
Logicvid 04 essay — compares Abhinavagupta, QFT, Russellian monism, and EM-field theories on the question of why reality appears.

## Approach

### Scene breakdown
1. **The Question** — Point of contention: boxed equation, clean centered claim
2. **Abhinavagupta's answer** — prakāśa + vimarśa + spanda as three inseparable terms
3. **Formal proof (A1-A5)** — Premise list with conclusion
4. **QFT vs Spanda** — Side-by-side comparison
5. **Russellian monism** — Refutation and counter
6. **EM field theory** — Third position
7. **Verdict** — Three-way comparison, final boxed equation

### Key design decisions
- Use `status: "refuted"` for positions that are rejected
- Use `status: "resolved"` for positions that survive
- Use `side-by-side` moves for comparisons
- Use `branch` moves for the three-way final comparison
- Clean white screen, no footer, centered typography

### Reusable pattern for Logicvid videos
```
Scene 1: The Question — claim with boxed equation
Scene 2: First position — premises + conclusion
Scene 3: Comparison — side-by-side or branch
Scene 4: Second position — refutation animation
Scene 5: Third position — converge or resolved
Scene 6: Verdict — branch (three-way) + final boxed claim
```
