# Anakhya — Sanskrit Publishing

## Identity
The future Sanskrit brand. Academic publishing, translated texts, deep scholarship. The long game.

## Guiding Principle
Texts that have survived millennia deserve presentation that lasts centuries. Not clickbait. Not trends. The source material is the authority.

## Content
- Tantraloka translations (ongoing)
- Academic papers on Pratyabhijñā, Spanda, Trika
- Critical editions of Sanskrit texts
- Deep dives into specific concepts (kañcukas, tattvas, upāyas)
- Yogi documentaries grounded in textual scholarship

## Format
`logical-argument` for academic papers
`semantic-essay` for conceptual deep dives
Long-form, slow pacing, ivory manuscript aesthetic
EB Garamond + Noto Serif Devanagari

## Website — The Platform
Anakhya is to Sanskrit philosophy what GitHub is to code — version-controlled, forkable, peer-reviewed, with AI-assisted tooling.

### Planned features
- **Digital library** with parallel Sanskrit + translation side-by-side
- **AI-assisted translation tools** — translate Navya-Nyāya and Tantra texts with AI, scholar-reviewable
- **Scholar accounts** — academics can suggest alternative translations, vote on the best one, discuss
- **Term tracking across texts** — search any term (e.g. *vimarśa*, *sphoṭa*, *apoha*) across 100+ texts, see how different schools translate it
- **School-based search** — filter by tradition (Pratyabhijñā, Madhyamaka, Nyāya, etc.)
- **Translation quality scoring** — the engine learns which translations scholars approve, ranks them
- **eReader** — read Sanskrit + translation side-by-side, tap any word for gloss, see its usage across all texts

## Competitive Landscape
| Project | What it does | What it doesn't do |
|---|---|---|
| sanskrittext.com | Digital Sanskrit library, some parallel texts | No AI translation, no scholar review, no cross-textual term tracking |
| github.com/sanskrit/sanskrit | Low-level linguistic tools (sandhi, sounds) | Not a publishing platform |
| indic-transliteration/sanscript.js | Script transliteration (IAST ↔ Devanagari) | Not translation, not analysis |
| GRETIL / Muktabodha | Digital Sanskrit text archives | No parallel translation, no AI tools |

Anakhya would be the first platform to combine: digital library + AI translation + scholar review + cross-textual analytics + the visual engine for producing content from the research.

## Why It Exists
The content I want to read properly formatted and contextualised. Not commentary — primary sources with apparatus. Also: AI is about to decode these texts at scale — someone needs to build the infrastructure for that to happen rigourously rather than chaotically.
