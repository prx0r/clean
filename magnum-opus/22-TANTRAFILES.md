# Tantrafiles — Yogi Explainers

## Identity
Popular tantra and yogi biographies. The Alan Watts / Asangoham lane but for Indian contemplative traditions. Warm, devotional-academic, accessible.

## Guiding Principle
Every yogi has a story that teaches something philosophy alone can't. The life IS the teaching. The biography format exists because it works — 1.9M views on Anandamayi Ma proves people want these stories.

## Content
- Yogi biographies (Anandamayi Ma, Ramana Maharshi, Nisargadatta, Abhinavagupta, Lalla, Maha Avtar Baba Ji, etc.)
- Essay companions (expansion essays as approachable videos)
- Practice guides (breath, meditation, mantra)
- Concept explainers (kañcukas, spanda, tattvas) in biographical context

## Format
Beat-map → `semantic-essay` motif
Gold standard pacing: 7.1s avg shot, 105 shots / 12 min
Script-first: PASS 1-5 from GoldThoughts methodology
Warm palette: gold/crimson/indigo on ivory
Voiceover + ambient audio (Tone.js at -30dB)

## Beat-Map Pipeline
1. GoldThoughts PASS 1: Write 3-5 min script (hook → build → reveal → implication → close)
2. PASS 2: Tag each narration line with visual beat
3. PASS 3: Write exact visual prompts per beat
4. PASS 4: Render + validate against pacing gold standards
5. PASS 5: Assembly + audio

## Website
`tantrafiles.xyz` — video library, essay archive, practice resources.
The video is the primary artifact; the website hosts and contextualises.

## Why It Exists
The stories I want to hear told properly. The format that already works. 1.9M people agreed.
